# Yandex Books to Readest

Скрипт для удобного переноса вашей библиотеки, прогресса чтения, цитат, заметок и закладок из **Яндекс Книг** (Bookmate) в **Readest**.

Импортирует книгу, обложку, цитаты, заметки, и ваш прогресс чтения, а так же некоторые метаданные книги

##  Установка

Проект использует сторонний сабмодуль для скачивания книг ([RU_Bookmate_downloader](https://github.com/kettle017/RU_Bookmate_downloader))

```
git clone --recurse-submodules https://github.com/aguilam/yandex-books-2-readest.git

cd yandex-books-2-readest

pip install -r requirements.txt

pip install -r bookmate_downloader/requirements.txt
```

## Использование скрипта
Вам понадобится ваш ID пользователя из Яндекс Книг (можно вводить и с @, но тогда надо писать в двойных кавычках), его вы сможете узнать из url вашей страницы в bookmate(ссылка примерно books[.]yandex[.]ru/@<Ваш UUID>/books/all) 

Если вы уже пользуетесь Readest: Зайдите в папку ваших книг Readest, скопируйте оттуда файл library.json и положите его в папку input/ этого проекта.

Книги (Опционально): Вы можете вручную закинуть папки скачанных книг в папку input/ с помощью утилиты описанной выше

Базовая команда для запуска скрипта выглядит так:

python main.py <ВАШ_UUID> [аргументы]
Доступные аргументы (флаги):

uuid (обязательный) — Ваш идентификатор пользователя в Яндекс Книгах.

--download — Автоматически скачать недостающие книги. Если скрипт видит, что у вас есть книга в Яндекс Книгах, но её нет в папке input, он попытается скачать её сам.

--sleep <число> — Время задержки (в секундах) между запросами к API Яндекс Книг. По умолчанию: 0.3. Помогает избежать блокировок.

--no-cache — Отключить использование кэша запросов (по умолчанию кэш включен, чтобы не нагружать сервера при повторных запусках).


Если вы запустили скрипт с флагом --download, сабмодуль начнет скачивать книги. Для этого ему нужен доступ к вашему аккаунту:
 - Во время работы скрипта откроется окно браузера с официальной страницей входа в Яндекс.
 - Вам нужно будет авторизоваться (ввести логин/пароль).
 - После успешного входа скрипт перехватит необходимый токен и начнет автоматическую загрузку книг.

Скачать все книги из вашей библиотеки:
```python main.py yandex_id --download```

Обработать только те книги, которые вы вручную положили в папку input/ (без скачивания):
```python main.py yandex_id```
## Завершение
После того как скрипт успешно завершит работу, все готовые данные появятся в папке output/

1. Откройте папку output/ в директории скрипта
2. Скопируйте Всё её содержимое
3. Вставьте это в папку вашей библиотеки Readest (обычно путь выглядит так: readest/books/). Согласитесь на замену library.json(Сделайте копию файла library.json, на всякий случай), если система спросит
